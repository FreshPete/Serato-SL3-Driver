# Active session pointer under packaged Windows callers

The longer Phase test exposed a cleanup-only failure: a live session pointer's `Path.resolve()` returned Codex's packaged-app cache location while the pointer's logical parent resolved to native Local AppData. The bundle verifier interpreted that difference as an escaped destination and refused the ordinary broker-stop dispatch. The same verifier passed before publication and after verified pointer withdrawal.

The destination check now treats the pointer as a logical filename under a resolved, contained parent directory. It returns the original hash-bound path spelling. Parent traversal, relative destinations and parent junctions resolving outside the allowed root are refused. An existing pointer leaf must be a regular file without a reparse attribute; directories and symbolic/reparse leaves are refused. Binary/package destinations keep the existing full-path containment check. Actual pointer withdrawal still checks its ownership record, exact contents/hash and controller process identity; destination validation alone does not authorize deletion or native rollback.

Five focused tests pass. They cover absent/existing regular pointers, a redirected regular leaf, retained locator spelling, outside/relative/traversal paths, an escaped parent and directory/symlink/reparse leaves. A separate actual Windows fixture in the existing SL3 user-data directory reproduced the observed redirection: the old check refused it, the new pointer check accepted it, and its contents and original path spelling were preserved. Only that uniquely created fixture file was removed. All 26 deployment checks and 22 session checks pass. No device was opened for these checks. The native DLL/worker binaries and their lifetime limits are unchanged. Existing source-bound capsules are intentionally stale after this script change and must not be reused; a fresh capsule, generated launcher, packaged installer resource and session plan are required. A live playback-and-cleanup retry remains necessary before calling the fix hardware-validated.
